1. Descripción general

El sistema Publicidad RELCO reproduce automáticamente videos e imágenes en pantalla completa sobre el monitor secundario al iniciar Windows. Está formado por un único script de PowerShell (mpv-publicidad.ps1) que gestiona la instalación, los accesos directos y el lanzamiento del reproductor mpv, un reproductor liviano de arranque instantáneo.

2. Requisitos previos

  • Windows 10 / 11
  • mpv descomprimido en C:\Program Files\mpv\ (ver sección 5)
  • Monitor secundario conectado y reconocido por Windows en modo Extender (puede aparecer como Ampliar según la versión de Windows)
  • PowerShell 5.0 o superior (incluido en Windows 10/11)

3. Estructura de carpetas

El script espera que los archivos de publicidad estén en:

C:\Users\Public\relco_videos\

Si la carpeta no existe, el script la crea automáticamente durante la instalación e indica al operador que debe agregar contenido.

Formatos soportados

ExtensiónTipoNotas
.mp4VideoH.264 recomendado
.jpg / .jpegImagenSe muestra 10 seg. por defecto
.pngImagenSe muestra 10 seg. por defecto

Los archivos se ordenan alfabéticamente por nombre. Para controlar el orden de reproducción, anteponga un prefijo numérico: 01_bienvenida.mp4, 02_oferta.jpg, etc.

4. Habilitar ejecución de scripts en PowerShell

Windows bloquea la ejecución de scripts de PowerShell por defecto. Antes de instalar, ejecute una sola vez el siguiente comando en PowerShell:

Opción A — Usuario actual (no requiere Administrador):
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Opción B — Todos los usuarios (requiere abrir PowerShell como Administrador):
Set-ExecutionPolicy RemoteSigned

Confirme con S cuando PowerShell lo solicite.

Verificación: puede comprobar que quedó aplicado ejecutando Get-ExecutionPolicy -List

5. Instalación

Pasos (única vez):
  1. Instale mpv antes de continuar. mpv no tiene instalador: se descarga un archivo comprimido y se descomprime a mano.
    Descarga: mpv.io/installation → sección Windows → compilación de 64 bits.
    Descomprima el contenido de modo que quede el archivo C:\Program Files\mpv\mpv.exe.
  2. Copie mpv-publicidad.ps1 a cualquier carpeta accesible.
  3. Abra PowerShell y navegue hasta esa carpeta:
    cd C:\ruta\donde\guardó\el\script
  4. Ejecute el script con el parámetro -Setup:
    .\mpv-publicidad.ps1 -Setup
Sin permisos de Administrador: si no puede escribir en C:\Program Files\, descomprima mpv en C:\Users\Public\mpv\ (debe quedar C:\Users\Public\mpv\mpv.exe). El script también lo busca ahí y en C:\Program Files (x86)\mpv\.
Importante: El script solo se instala cuando se ejecuta con -Setup desde PowerShell. Sin ese parámetro únicamente lanza mpv (es el modo que usan los accesos directos ya instalados).

Durante la instalación el script:

  • Verifica que mpv esté presente (muestra un cartel con la ruta esperada si no lo encuentra).
  • Se copia a C:\Users\Public\mpv-publicidad.ps1.
  • Crea un acceso directo "Publicidad RELCO" en el Escritorio.
  • Crea un acceso directo en Inicio automático del usuario actual, para que arranque con Windows.
  • Abre el panel de selección de pantalla (igual que presionar Win + P): seleccione Extender (o Ampliar) para activar el monitor secundario.
  • Crea la carpeta C:\Users\Public\relco_videos\ si no existe.
Nota: Una vez completada la instalación, copie el contenido a relco_videos\ y use el acceso directo del escritorio para iniciar la publicidad.
Pantalla táctil: Al cambiar al modo Extender/Ampliar, Windows puede confundirse y perder el tacto en la pantalla principal (los toques se registran en la pantalla incorrecta). Para corregirlo:
  1. Presione Win + R, escriba tabletpc.cpl y presione Enter.
  2. Haga clic en Configurar.
  3. Siga las instrucciones y toque la pantalla táctil cuando se le indique.
Esto recalibra qué monitor reconoce Windows como pantalla táctil.

6. Acceso directo en el Escritorio

Tras la instalación aparece el icono "Publicidad RELCO" en el escritorio. Úselo para:

  • Relanzar la publicidad después de cerrarla manualmente.
  • Aplicar cambios de playlist: cada vez que agregue, quite o renombre archivos en relco_videos\, cierre la publicidad (sección 7) y haga doble clic en este acceso directo para que mpv cargue la nueva lista.
Tip: mpv no detecta cambios en la carpeta en tiempo real. Siempre cierre y relance desde el acceso directo del escritorio para reproducir el contenido actualizado.

7. Cómo cerrar la publicidad

Mientras la publicidad está activa, mpv ocupa toda la pantalla secundaria. La ventana está oculta de la barra de tareas de forma intencional para no interferir con el escritorio, y mpv no muestra ningún icono junto al reloj. Para cerrarla, elija cualquiera de estas opciones:

Opción A — Con el teclado (recomendada):
  1. Haga un clic sobre la pantalla de publicidad para darle el foco.
  2. Presione la tecla Q. mpv se cierra de inmediato. También funciona Alt + F4.
Opción B — Administrador de tareas:
  1. Presione Ctrl + Shift + Esc.
  2. Busque mpv (o mpv.exe) en la lista de procesos.
  3. Haga clic derecho → Finalizar tarea.
Nota: si al presionar Q no pasa nada, el foco quedó en otra ventana. Vuelva a hacer clic sobre la pantalla de publicidad e intente de nuevo.

8. Actualizar el contenido de publicidad

  1. Copie los nuevos archivos (.mp4, .jpg, .png) a C:\Users\Public\relco_videos\.
  2. Elimine o renombre los archivos que ya no deban reproducirse.
  3. Cierre la publicidad: clic sobre la pantalla secundaria y tecla Q (sección 7).
  4. Haga doble clic en el acceso directo "Publicidad RELCO" del escritorio para reiniciar con la nueva lista.

9. Parámetros configurables

Los siguientes valores se pueden ajustar editando las primeras líneas del script:

VariableValor por defectoDescripción
$MediaFolderPublic\relco_videosCarpeta de contenidos
$ImageDuration10 (segundos)Tiempo por imagen
$SecondaryScreen10 = primaria · 1 = secundaria

Tras cualquier cambio en el script, vuelva a ejecutarlo con -Setup para reinstalar los accesos directos.

10. Solución de problemas

SíntomaCausa probableSolución
La publicidad no arranca al encender el PC Acceso directo de inicio automático no creado Ejecutar el script con -Setup
Cartel "mpv requerido" / "mpv no encontrado" mpv no está descomprimido en una ruta esperada Verificar que exista C:\Program Files\mpv\mpv.exe (o C:\Users\Public\mpv\mpv.exe) y volver a ejecutar
Pantalla negra / sin contenido Carpeta relco_videos vacía Agregar archivos y reiniciar con el acceso directo
El video sale en la pantalla incorrecta Valor de $SecondaryScreen Cambiar a 0 o 1 según corresponda
La publicidad aparece en la pantalla principal o en ambas Windows no quedó en modo Extender Presione Win + P y seleccione Extender (o Ampliar). La instalación lo configura automáticamente, pero algunos equipos revierten el modo al reiniciar.
La pantalla táctil no responde o los toques se van a la pantalla equivocada Al activar Extender/Ampliar Windows puede reasignar el táctil al monitor secundario Presione Win + R, escriba tabletpc.cpl y presione Enter → haga clic en Configurar → toque la pantalla táctil cuando se le indique.
Las imágenes se ven muy poco tiempo $ImageDuration bajo Aumentar el valor en el script y relanzar
mpv aparece en la barra de tareas Error al ocultar la ventana Cerrar con Q y relanzar desde el acceso directo
Necesita enviar un diagnóstico a soporte — El script deja un registro por día en %TEMP%\relco_publicidad\ (Win + R → %TEMP%\relco_publicidad). Adjunte el archivo .log de la fecha del problema.

11. Desinstalación

  1. Cierre la publicidad (sección 7).
  2. Elimine el acceso directo del Escritorio: Publicidad RELCO.lnk
  3. Elimine el acceso directo de inicio automático en:
    C:\Users\<usuario>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\
  4. Elimine C:\Users\Public\mpv-publicidad.ps1 si lo desea.
  5. Opcional: elimine la carpeta C:\Program Files\mpv\ para quitar el reproductor.
